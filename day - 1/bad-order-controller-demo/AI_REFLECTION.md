# AI Reflection

I used Antigravity as a substitute for Claude Code and Copilot because I did not have access to those tools. During the Strategy Pattern refactor, it correctly identified the discount calculation as a good candidate and moved the VIP and loyal-customer rules into separate strategies. I did catch an issue in its first proposal, though. It suggested using `Max()` to select the discount, which would have changed the original first-match behavior. I pushed back and we changed it to priority-based evaluation so VIP still takes precedence.

The test-generation round saved me time writing the basic Arrange/Act/Assert structure. The generated tests for negative and zero quantities exposed a real validation gap in `OrderService`. The existing code only checked whether stock was less than the requested quantity, so a negative quantity could pass through. After reviewing the test failures, I fixed the bug by explicitly throwing an exception for any quantity less than or equal to zero, ensuring the generated tests passed against the updated production code. The test for an empty order passed immediately because that validation was already present. This was a good reminder that a generated test can expose a real issue that requires human review and fixing.

If I were debugging production at 2 AM, I would probably reach for an agentic tool first to help trace the code and narrow down the problem. I would still verify its suggestions myself, especially around business rules. In this exercise, the most useful part wasn't the code it generated by itself, but catching where its first solution changed existing behavior.
